# VibePlayer

Player desktop para cursos em vídeo guardados no seu computador, com um assistente de IA ao lado do vídeo.

Comprou um curso que veio só com os arquivos de vídeo, sem plataforma? O VibePlayer organiza as aulas e, enquanto você assiste, permite:

- fazer perguntas sobre o conteúdo da aula;
- gerar um resumo da aula;
- ver os principais pontos, com links que levam o vídeo direto ao momento certo.

Funciona no **Windows**, **macOS** e **Linux**. A IA pode ser o Claude (Anthropic) ou um modelo local via Ollama.
